# 上市公司年报

管「抽什么」：实体范围、推荐谓词、文档特有约束。名称清洗、对齐、落库仍走确定性代码，本 skill 不改写防幻觉门禁。

## 实体范围

- 上市公司及其子公司
- 参股主体与联营企业
- 董事、监事与高管
- 业务板块
- 产品与服务
- 主要客户与供应商
- 财务指标
- 重大投资项目
- 对外担保与诉讼

## 推荐谓词

- 控股
- 参股
- 子公司
- 销售给
- 采购自
- 投资
- 营收来自
- 属于
- 计提
- 担保
- 任职
- 披露

## 补充约束

- 客户/供应商若原文只写「第一名客户」「前五大供应商」，就用原文称呼，不要编造具体公司名。
- 分季度、分行业、分地区的数据归到同一个指标实体，不要拆成多个名字相近的点。
- 「本公司」「公司」指上市公司本身，统一用其全称。
