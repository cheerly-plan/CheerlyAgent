# 招股意向书

管「抽什么」：实体范围、推荐谓词、文档特有约束。名称清洗、对齐、落库仍走确定性代码，本 skill 不改写防幻觉门禁。

## 实体范围

- 发行人及其子公司
- 控股股东与实际控制人
- 董事、监事、高管与核心技术人员
- 主要产品与型号
- 原材料与生产设备
- 募投项目
- 资质许可与专利
- 监管与审批单位
- 财务指标
- 重大风险事项
- 中介机构

## 推荐谓词

- 控股
- 全资子公司
- 参股
- 聘请
- 生产
- 采购
- 供应
- 销售
- 募投包含
- 拥有资质
- 持有专利
- 投资
- 审批
- 属于
- 担任
- 依赖
- 应用于
- 同比增长

## 补充约束

- concept 只用于行业赛道（如「民爆行业」「风电运营」），不要用于普通业务抽象词。
- 财务指标抽指标名（「营业收入」「装机容量」），不要抽成「营业收入 120 亿元」或「62,200万千瓦」这种带数值的整句；具体数字和年份写进说明。不要把「流动资产」「其他流动资产」这类科目名单独当实体。
- 母公司与子公司是不同实体，不要把子公司并进发行人。
