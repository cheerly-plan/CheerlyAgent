# 上市公司季报

管「抽什么」：实体范围、推荐谓词、文档特有约束。名称清洗、对齐、落库仍走确定性代码，本 skill 不改写防幻觉门禁。

季报不复用年报的「财务指标尽量抽全」：要回答的是股份、营收来源、机构和资金往来；利润表每一行建成孤立 metric 没有边，也答不了这些。

## 实体范围

- 上市公司本身
- 股东与持股机构（含基金、资管计划）
- 子公司、参股公司与联营公司
- 董事、监事、高管与会计机构负责人
- 营业收入的业务或主体来源
- 有对手方的资金往来（借款、担保、重大理财）

## 推荐谓词

- 持股
- 控股
- 参股
- 子公司
- 任职
- 营收来自
- 借款
- 担保
- 投资

## 补充约束

- 只抽股份、营收来源、机构和资金往来。资产负债表、利润表、现金流量表的科目（货币资金、应收账款、净利润、经营活动现金流、每股收益等）不要建成实体。
- 持股的方向是持有人指向被持股公司：主体是股东或机构，客体是上市公司。股数和比例写在说明里，不要单独成点，也不要写成公司持股股东。
- 「营收来自」的客体只能是业务板块、产品或子公司，不要连到「营业收入」这个科目名，也不要连到在手订单、新签订单。
- 资金只抽能指出对手方的往来（向谁借款、为谁担保、买了谁的理财），金额写在说明里。没有对手方的科目余额不抽。
- 「本公司」「公司」指这份季报封面的上市公司全称，不要用其他文档里的公司名。
- 客户或供应商若原文只写「第一名客户」，就用原文称呼，不要编造公司名。
- 季报没披露的关系不要脑补。
