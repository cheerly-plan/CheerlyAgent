# 尽调报告

管「抽什么」：实体范围、推荐谓词、文档特有约束。名称清洗、对齐、落库仍走确定性代码，本 skill 不改写防幻觉门禁。

## 实体范围

- 标的企业
- 股东与实际控制人
- 关联方
- 核心人员
- 资质与知识产权
- 主要资产
- 重大合同
- 客户与供应商
- 财务与税务事项
- 诉讼、处罚与合规风险

## 推荐谓词

- 持有
- 控制
- 关联
- 签署
- 供应
- 采购
- 抵押
- 质押
- 涉诉
- 处罚
- 承诺
- 依赖
- 出资

## 补充约束

- 问题清单里的「存在……风险」要连到具体主体或资产，不要只留一个抽象风险词。
- 访谈记录、资料清单里的一问一答不要当关系抽，只取陈述性事实。
