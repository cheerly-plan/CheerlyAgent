# 公司公告

管「抽什么」：实体范围、推荐谓词、文档特有约束。名称清洗、对齐、落库仍走确定性代码，本 skill 不改写防幻觉门禁。

## 实体范围

- 上市公司
- 交易对方
- 标的资产或标的公司
- 董事、监事与高管
- 股东
- 担保与借款
- 监管机构
- 中介机构

## 推荐谓词

- 收购
- 出售
- 增资
- 减持
- 质押
- 担保
- 聘任
- 辞职
- 审议通过
- 披露
- 停牌

## 补充约束

- 「本公司」「公司」指上市公司本身，统一用其全称。
- 金额与时点只在构成关系时顺带写进说明，不单独成实体。
