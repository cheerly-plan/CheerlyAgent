# 行业横向对比

管「写什么」：行业横向对比大纲与默认指标集。抽数、同比环比、数字校验、PDF 落盘仍走确定性工具，本 skill 不改写防幻觉门禁。

## 大纲

### 覆盖范围

先写清行业、报告期和实际调到的公司。没调到的公司不出现。

### 主要指标与出处

只写{indicators}。每个数字都要能回到文件和页码，抽取没有的数不写。

### 同比与环比

增减额和幅度只用计算工具的结果，不在正文里重算。

### 公司间对比

只对比同一报告期、同一口径都抽到的指标。

### 缺失说明

列出没有季报或没有对应指标的公司，不补估计值。
