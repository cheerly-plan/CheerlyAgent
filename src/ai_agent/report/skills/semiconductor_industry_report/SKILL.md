# 半导体行业财报对比分析

管「写什么」与「盯哪几家、归哪条赛道」。数字只来自已入库/自动补齐的公司财报；
不做估值分位、不做买卖建议。行业景气与国产化率等外部数据源未接时，只在「下期预告」
留白，不编造宏观增速。

代表公司（按赛道）：制造中芯国际；设备北方华创、中微公司、中科飞测；设计韦尔股份、兆易创新、寒武纪；封测长电科技。

## 大纲

### 阅读说明

交代期间口径、合并／母公司范围、单位不自行折算；写明三级归因边界——①已抽取数字事实可写；②原文经营说明须标出处；③无出处的第三方推断一律不写。

### 赛道分组

按设计／制造／设备／封测列出本期覆盖的代表公司；只陈述分组与是否抽到本期财报，不写赛道景气度。

### 组内对比

只在同一赛道内对比{indicators}；跨赛道不混排同一张表。没抽到的公司／指标进缺失说明。

### 经营解读

只根据已抽取指标与季报原文解释经营现象；每个因果句必须能指回已授权数字或原文证据，否则不写；不写同业均值、估值与投资建议。

### 趋势与对比图

两点同比对比用柱状图；不足四期不画折线趋势。图注标明对比期与口径。

### 缺失与口径

列出未调到的季报、未抽到的指标与口径不齐项；不写投资建议。

### 下期预告

景气周期（全球销售额增速、稼动率、价格等）待接入外部数据源（WSTS／SEMI／协会）；本期不推断周期位置。下一期需明确：数据源清单、入库表结构、更新频率。
