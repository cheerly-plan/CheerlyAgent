# 半导体行业财报对比底稿

管「写什么」与「盯哪几家、归哪条赛道」。数字只来自已入库/自动补齐的公司财报；
不做估值分位、不做买卖建议。行业景气与国产化率等外部数据源未接时，只在「下期预告」
列数据源清单，不编造宏观增速。本交付定位为财报对比底稿，不称行业深度研究。

代表公司及赛道分组以文件头 `companies` 字段为唯一来源，由系统按赛道自动展开；正文不重复列举，新增公司只改该字段一处。

## 大纲

### 阅读说明

section: reading_note

交代期间口径、合并／母公司范围；金额默认统一折算为元（原单位见指标表脚注）；写明三级归因边界——①已抽取数字事实可写；②原文经营说明须标出处；③无出处的第三方推断一律不写。明确本文为财报对比底稿。

### 赛道分组

section: segment_roster

代表公司（按赛道）：{companies}。只陈述分组与是否抽到本期财报，不写赛道景气度。

### 组内对比

section: segment_peer

只在同一赛道内对比{indicators}；跨赛道不混排同一张表。没抽到的公司／指标进缺失说明。

### 同比与趋势

section: change

有同口径基期则写同比（及可写的环比）；缺基期或口径不齐时显式写「不可比／缺基期」，不放弃趋势议题，亦不编造增减。

### 经营解读

section: analysis

先写结构比率梯队；若知识库召回季报经营分析原文，以「原文披露」带页码／文件标识引述作有出处归因；无原文则归因从略，禁止无出处推断。不写估值与投资建议。

### 趋势与对比图

section: chart_guide

两点同比对比用柱状图；不足四期不画折线趋势。图注标明对比期与口径。

### 缺失与口径

section: gaps

列出未调到的季报、未抽到的指标与口径不齐项；不写投资建议。

### 下期预告

section: next_period

景气周期待接外部数据源（WSTS／SEMI／协会等）；正文列建议数据源清单与入库要求。接入前本报告只做公司财报赛道分组对比底稿，不构成行业深度研究。
