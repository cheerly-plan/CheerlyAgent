# 公司财报深度分析

管「写什么」：大纲。默认指标集由 `industry.company_type_of` 按主体细类型路由
（Fabless 看毛利率／研发／存货周转；设备看合同负债／存货／在手订单；Foundry 看稼动率／CAPEX…），本 skill 的
`indicator_set: generic` 仅作兜底。抽数、同比环比、数字校验、PDF 落盘仍走确定性
工具，不改写防幻觉门禁。

空 `industries` = 该 kind 下的通用兜底模板（非银行主体走这里）。

## 大纲

### 本期结论

用 3–5 句提炼主线（营收、利润、毛利率等），数字必须来自本期已抽取的指标；完整清单放「主要指标与出处」，不在这里平铺。

### 主要指标与出处

只写{indicators}。每个数字都要能回到文件和页码，抽取没有的数不写。

### 同比与环比

增减额和幅度只用计算工具的结果，不在正文里重算。

### 单季节奏

只用季报「本报告期」列与它自带的单季同比，和累计同比并排看节奏，不由累计值倒推。

### 较上年末变动

只用原文「比上年末」句，区分期末时点存量与累计发生额。

### 数据观察

只并列原文披露的数字关系，不写因果归因；口径交代不全的地方如实标明。

### 经营解读

只根据已抽取指标与季报原文解释经营现象；无原文支撑的因果不写；不写同业均值、估值与投资建议。

### 趋势

只使用已经调取到的对比期，没有的期间不画、不写。

### 缺失与口径

写明合并还是母公司。缺失项直接列出。
